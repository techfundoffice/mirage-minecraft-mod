# Mirage Minecraft Mod v1.0.0

**Release Date**: 2025-11-28  
**Minecraft Version**: 1.21.8  
**Fabric Loader**: 0.17.2+

## 🎮 Overview

Transform your Minecraft game into any style or world you can imagine, in real time. Powered by [Decart's Mirage](https://mirage.decart.ai) live video restyling model.

## 📦 Installation

### Requirements
- ✅ Minecraft Java Edition 1.21.8
- ✅ Fabric Loader 0.17.2 or higher
- ✅ Fabric API 0.133.4+1.21.8
- ✅ Java 21 (JDK 21 or higher)

### Quick Install
1. Download `mirage-minecraft-mod-1.0.0.jar` from this release
2. Install [Fabric Loader](https://fabricmc.net/use/) for Minecraft 1.21.8
3. Install [Fabric API](https://modrinth.com/mod/fabric-api) 0.133.4+1.21.8
4. Place the mod JAR in your `.minecraft/mods/` folder
5. Launch Minecraft with the Fabric profile

## 🐛 Troubleshooting

### Common Issues

**Q: Game crashes on startup**
- Ensure you have Java 21 installed
- Verify Fabric API is installed
- Check that you're running Minecraft 1.21.8

**Q: "Failed to initialize GLFW" error**
- This mod requires a graphical environment
- Cannot run on headless servers

**Q: Mod doesn't appear in mod list**
- Verify the JAR is in the correct `mods/` folder
- Check Fabric Loader is installed for version 1.21.8
